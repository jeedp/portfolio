01 About

I'm a 4th-year Computer Engineering student at Southern Leyte State University in the Philippines, working toward a career in software engineering. My projects usually sit where code meets a physical device, and I care about the part people touch: a kiosk screen, a dashboard, a form that doesn't break.

Right now I'm finishing my thesis, the SLSU Campus Wayfinding System. During my internship I fixed and documented five bugs in a production Laravel system used for internal audits.

I'm learning more about testing and maintainable architecture, how data moves between systems, and designing hardware and software as one system. AI and machine learning are next on my list.
