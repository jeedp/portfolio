SLSU Campus Wayfinding System

Thesis, team of two, in progress

An offline touchscreen kiosk that guides students and visitors to any building, office or facility on campus, and keeps working when the network drops.

  • Made the map fast enough for a Raspberry Pi 4 by shrinking every floor drawing.
  • Built the QR hand-off that continues a route on a visitor's own phone with live GPS.
  • Wrote the setup script and guide that turn a blank SD card into a working kiosk.

Floor drawings cut from 14 MB to 1.5–3 MB each, so the map runs smoothly on the Pi.

Smart Parking Gate System

IoT, solo project

A parking gate that opens for RFID card holders, counts free slots with ultrasonic sensors and shows both on a live web dashboard.

  • Built everything myself, from pin mapping and firmware to the dashboard.
  • Added Bluetooth control so an operator can open the gate from a browser, even with no internet.
  • Wrote unit tests for the gate and RFID logic.

Gate control and network updates run as separate FreeRTOS tasks on separate cores, so a slow connection never holds the gate.

  • C++
  • ESP32
  • FreeRTOS
  • PlatformIO
  • Firebase
  • Bluetooth LE
